# E-Commerce Customer Behavior and Purchase Conversion Analysis

## Overview

This project analyzes e-commerce customer behavior using the OTTO Recommender Systems Dataset.

The objective is to identify behavioral patterns associated with purchase conversion and derive actionable business recommendations.

## Research Objectives

- Analyze user interactions during e-commerce sessions.
- Compare purchased and non-purchased sessions.
- Investigate the click-to-cart-to-purchase funnel.
- Examine associations between session behavior and purchase conversion.
- Develop data-driven business recommendations.

## Dataset

Source: [OTTO Recommender Systems Dataset](https://github.com/otto-de/recsys-dataset)

The dataset contains anonymized e-commerce session events, including:
- Clicks
- Cart additions
- Orders

The raw dataset is not stored in this repository.

## Methodology

The project follows the six stages of CRISP-DM:

1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Modeling / Analysis
5. Evaluation
6. Deployment / Recommendations
